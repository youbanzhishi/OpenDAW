### 根因: plugin-host crate 有2个编译错误

#### 错误1: chain.rs:51 - ChainNode 不是迭代器
- 代码: self.nodes.remove(index).map(|n| n.plugin)
- 原因: Vec::remove() 返回 T，不是 Option<T>，所以没有 .map() 方法
- 修复: 先检查边界再 remove

#### 错误2: chain.rs:136-137 - 生命周期不足
- 代码: pub fn get_plugin_mut(&mut self, index: usize) -> Option<&mut dyn VcPlugin>
- 原因: trait object dyn VcPlugin 默认有 static 生命周期，但实际返回值绑定了 &mut self 的生命周期
- 修复: 添加 + '_ 生命周期绑定
